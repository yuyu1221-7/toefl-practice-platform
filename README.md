# TOEFL Practice Platform

A browser-based exam practice and assessment system built with HTML and JavaScript.

The project provides reusable workflows for structured question banks, practice sessions, timed mock exams, answer review, progress tracking, local persistence, and optional AI-assisted tools.

## Features

- Structured JSON question banks
- Practice and timed mock-exam modes
- Multiple-choice and fill-in-the-blank questions
- Exam timers and navigation
- Answer review
- Local progress persistence
- Attempt history and export
- Responsive desktop, tablet, and mobile interfaces
- Question-bank search
- Optional AI-assisted workflows

## Project Goal

This project began as a TOEFL practice tool but also serves as an experimental browser-based assessment platform.

Many of its components, including question-bank loading, exam navigation, browser persistence, review workflows, and responsive interfaces, can be adapted for other educational assessment systems.

## Technology

The project primarily uses:

- HTML
- JavaScript
- Tailwind CSS
- LocalStorage / browser persistence
- Structured JSON data
- Optional external AI APIs

The application can be deployed as a static website using GitHub Pages.

## Privacy and API Keys

Most application data is stored locally in the user's browser.

Optional AI features may require an external API key. API keys stored in browser storage should not be considered completely secure. Users should use appropriately restricted keys and avoid exposing credentials publicly.
